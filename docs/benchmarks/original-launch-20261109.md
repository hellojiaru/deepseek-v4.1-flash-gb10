# 原始模型启动入口实测

实际使用发布树的`tools/serve_original.py`启动四rank和配对前端，官方1017权重、C4、同一套干净构建的二进制。候选没有加载向量文件或scope。前后控制组为现有服务的Normal路径：原服务 → 独立候选 → 原服务，完整停止与恢复有单独运维回执。

每阶段按固定顺序运行8类任务、每类3次，共24次响应：代码、文章、Agent诊断规划、JSON、算术、实验推理、翻译、摘要。temperature 0、seed 42、关闭思考、每请求最多512输出tokens，允许自然结束。全部三组各10,463输出tokens。

| 阶段 | 总输出／生成时间 | 总输出／请求时间 | 请求生成速度中位数 |
|---|---:|---:|---:|
| 前控制Normal | 105.29 tok/s | 102.45 tok/s | 113.27 tok/s |
| **无向量原始入口** | **105.08 tok/s** | **102.29 tok/s** | **112.35 tok/s** |
| 后控制Normal | 105.09 tok/s | 102.32 tok/s | 112.78 tok/s |

原始入口相对前后控制均值变化约-0.11%，属于本轮重复波动范围，不能当作性能损失或新的优化收益。三组24/24输出SHA一致。该固定8类短任务是当前构建的补充验收，与历史日常长Agent记录分开。

原始候选另外通过：

- `/v1/models`仅列出一个不带模式后缀的原始模型。
- 未配置向量时，Creative别名返回400。
- 函数调用、参数解析、工具结果返回后读取37的往返通过。
- 真实双色图片右半部分识别为蓝色。
- 约65K前缀续接实际复用65,008tokens。

启动器CPU控制还验证：父环境残留向量路径和scope不会传入原始子进程；显式启用时只传入本次提供的资产。打包器拒绝非单位范数方向。原始入口不会限制用户后来选择可选向量功能。

所有模型测试结束，原C4二进制、参数、完整环境、双模式及配对前端恢复，vision与温控未重启。获准维护导致原活跃KV冷启动，不承诺跨重启缓存命中。源码与逐请求结果、失败及恢复日志保持私有；同名JSON提供公开数值和SHA。
