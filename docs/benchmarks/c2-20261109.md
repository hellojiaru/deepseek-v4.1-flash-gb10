# C2 reference

Two requests run concurrently on the restored four-slot C4 service, using the same code/prose prompts and `Independent worker` prefixes as the existing C4 group test. Temperature 0, seed 42, reasoning off, 512 output tokens per request, three repetitions per workload.

| Workload | Mean group decode throughput |
|---|---:|
| Code | **148.80 tokens/s** |
| Prose | **127.60 tokens/s** |

Each group starts through a two-party barrier. The aggregate metric is the sum of `(completion_tokens-1)` divided by the time from the first stream's first content to the last stream's DONE, including any intervening prefill pauses. End-to-end throughput from request submission is recorded separately. All 12 requests completed with 512 output tokens each.

This fills the C2 reference point; it does not change slot allocation or deploy another model. `tests/integration/probe_c2.py` is the reproducible entry point; same-name JSON contains all six groups and raw-result SHA.
